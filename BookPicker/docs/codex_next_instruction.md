読了にする操作について。

ボタンを押した場合は、現在のBookのCurrentPageとTotalPagesを確認してください。

CurrentPageがTotalPages未満の場合は、すぐにAPIを呼び出さず、ユーザーへ確認を行ってください。

確認内容では、読了にするとCurrentPageがTotalPagesへ変更されることを明確に伝えてください。

例えば以下の意味が伝わる内容にしてください。

現在の進捗は100 / 180です。

読了にすると現在ページが180へ変更されます。

読了にしますか。

読了APIについて。

読了にする場合は、

PUT /api/books/{id}/completion

へ

isCompleted = true

を送信してください。

既存APIのRequest形式を正確に確認して使用してください。

成功時はバックエンド側で以下が行われる現行仕様です。

CurrentPageがTotalPages未満ならTotalPagesへ変更。

IsCompletedをtrueへ変更。

ReadingStatusをCompletedへ変更。

LastReadAtを現在のUTC日時へ更新。


これらのロジックをJavaScript側で重複実装しないでください。

JavaScript側でCurrentPageをTotalPagesへ変更してから一般編集APIを呼ぶような実装にはしないでください。

completion APIだけを使用してください。


読了解除について。

IsCompletedがtrueの場合は「読了解除」ボタンを表示してください。

押した場合は

PUT /api/books/{id}/completion

へ

isCompleted = false

を送信してください。

現行仕様では、読了解除時に以下となります。

IsCompletedはfalse。

CurrentPageは変更しない。

LastReadAtは変更しない。

ReadingStatusは現在のCurrentPageとTotalPagesから再計算。

この挙動をJavaScript側で再実装しないでください。


読了解除については、今回は必須の確認ダイアログを追加しなくて構いません。

ただし誤操作しやすい配置にはしないでください。
